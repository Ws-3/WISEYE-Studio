# 红外外观试验第一版（2026-10-26）

已在真实Small City中运行并采集同一云台视角的新旧对照。该版本改动相机成像材质，不改地图几何、城市材料资产、设备尺寸或用户Fleet位置。

2026-10-27城市独立Shipping包已实际验证：增强材质可用，ptz-02原始/增强模式差25.37、白热/黑热互补误差0.86、噪声差1.89，IR640×512、VIS1920×1080，四种非法请求拒绝且不改状态，结束后恢复参数。数值仅表示同视角图像差异，不是成像真实性评分；证据见`evidence/standalone-release-20261027/infrared/report.json`。

## 如何试用

20261027完整Shipping版本包含增强红外材质与参数控制，独立包直接双击WISEYE.exe，启动后在云台红外属性中设置。实际交付及发布版验收见[RELEASE_BUILD.md](RELEASE_BUILD.md)。旧20261023完整包和20261026桌面接口更新ZIP均不包含本次UE红外改动。

以下是保留的源码试验入口。先降落并关闭之前的UE/系统/飞控，释放50051和50052；在PowerShell执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\WISEYE-Studio\scripts\Start-InfraredPreview.ps1"
```

脚本使用 `E:\Projects\WISEYE-BuildWorkspace` 的已编译Editor模块运行独立游戏窗口，并打开新版源码桌面和后台飞控。首次会在该目录 `builds/infrared-preview-data` 中复制独立配置，保留原项目配置。保持启动PowerShell窗口开启，等城市场景加载完成后在桌面连接UE。

预览数据目录的Content是指向已有内置构建资产的目录联接，用于桌面识别已安装场景，不复制城市资源。此轮请专注成像参数，地图导入等内容制作仍在正式开发流程进行。

选择云台，打开红外属性页：

- 成像模式：增强热像（试验版） / 原始热像（对照）。同一视角切换后等待约一秒或至少三个新采集帧再观察/保存。
- 光学模糊：0～2个红外输出像素，默认0.8；先用0.5～1比较，避免丢失小目标。
- 明暗对比：0.3～3，默认1.35；它是固定窗口的对比调节，尚非自动增益控制。
- 背景层次：0～1，默认0.65；增强表面形状和少量纹理层次。
- 传感器噪声：保留原0～0.1范围，默认0.008；对比画面中的0.03只是演示，不是推荐真实相机噪声标定值。
- 白热/黑热极性、FOV、按设备启停和原始单帧仍可用。参数按云台隔离、应用后回读，当前仅本次运行有效。

先降落，再关闭游戏和桌面；启动脚本在游戏关闭后停止自己启动的飞控进程。预览数据改动不自动合并回正式Fleet。旧UE不具备新材质时，新控件禁用且不提交新参数。

## 实现与边界

独立 `/Game/WISEYE/Sensors/M_IR_Experimental` 材质优先加载，原 `M_IR_Minimal` 完整保留。试验材质包含原公式分支，可以不换位置做A/B；缺新材质时回退原模式，不让界面假报新能力。

增强分支增加五点近似光学模糊、帧间变化的噪声与固定图案噪声、距离衰减近似、表面法线层次和弱可见光纹理代理；热目标从原Stencil热度映射为更温和的对比。噪声按每传感器采集帧序号变化，未新增CPU整帧后处理或额外GPU读回。可见光保持原采集链路。

它不是经过测量的PSF/MTF、NETD或辐射传输模型；可见光纹理代理不是发射率。尚未加入材质温度分类、电机升温/冷却、平滑AGC或真实数据校准。仍沿用原CustomDepth/Stencil遮挡链路，未新增独立热掩码，也未验证与任意外部实例分割配置共存。不能声称已达到Anti-UAV数据域或辐射精度。

城市对照中建筑与道路层次有所增加，仍偏均匀灰；下一步应为道路、混凝土/玻璃、植被等主要材质建立热特性，而不是继续单纯加噪声或拉高对比度。远距离小目标与多设备GPU耗时仍需专门验证。
