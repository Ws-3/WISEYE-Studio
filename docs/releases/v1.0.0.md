# WISEYE Studio v1.0.0 · 生日纪念版

发布日期：2026 年 11 月 3 日。

🎂 **11 月 3 日是作者的生日。** 今天发布 WISEYE Studio 首个功能较完整的阶段版本，作为项目的里程碑，也作为送给自己的生日纪念。

## 本版功能

- 仿真端与独立训练/数据采集端，统一深灰蓝界面、场景编排、设备管理与参数设置。
- 默认小城市，以及独立加载的大城市试验场景；移除通用测试/沙漠场景入口。
- Mavic/Avata、自动航线与键盘控制、真实转速、起降与碰撞恢复、设备放置模型预览。
- 云台角度、视场角、距离遥测、自定义仿真地理基准和坐标指向接口。
- 独立光心的可见光 1920×1080、红外 640×512、激光点云及默认关闭的事件相机；各传感器单独启停。
- 参考实拍改进红外建筑/天空/目标灰度、局部热斑、稳定增益，以及夜空、导航灯和空间雨线。
- 可编辑 RTSP 等接口、低延迟预览、双路图像与真值采集、工作台启动训练端。
- 启动/关闭仿真与连接/断开控制、所属进程退出保护；启动界面不默认启动 UE。
- Win64 Shipping 便携打包，仿真端、训练端及流工具封装，配置与输出保存在旁边 UserData。

## 当前限制

- 大城市仍为试验功能；未完成干净第二台 Windows、长时间、多机和全城压力验收。
- 红外尚非辐射温度标定，事件是帧驱动近似且可能截断/丢弃，天气非完整物理降水模型。
- 真值采集速率受硬件影响，设置帧率不等于实测帧率；可选算法框架与权重并未全部随包提供。
- 尚无正式签名安装器或在线更新器。
- F 盘迁移暂缓，最新工作代码位于 E 盘；开发仍需本地 UE 与城市依赖。

完整第三方 City Sample、引擎、Python 环境、用户数据、缓存和大型运行包不上传源码仓库。迁移副本遗漏的历史已跟踪 UE 资源从 Git 恢复保留，避免误提交为资产删除；旧场景入口仍保持移除。
