## 主要变化

- 安装到任意 UE 5.8 C++ 宿主场景；无 City Sample/Traffic 时明确关闭城市人车能力，核心双光和无人机不强制依赖城市资源。
- 插件保留 `/Script/test` 和历史 `/Game` 资产兼容路径，安装前校验哈希、目标路径和冲突；拒绝同名 test 模块及覆盖不同内容的宿主文件。自定义场景 ID、通用飞控模板和独立用户数据入口已接通。
- 源码、设备资源与默认 UE 工程集中在同一仓库；旧外部 IR-Work/Evaluation 工程已退出活动依赖并隔离，城市原始资源仍作为可选开发依赖。
- 中英界面、80 cm 固定翼、JSBSim 六自由度参考气动、设备实时增删和参数修改；保存初始设置与应用当前运行场景分开。
- 每机独立航拍红外/可见光，双光并排；可见光模糊、噪声、对焦和景深近似，改进道路/建筑等红外热外观与局部热特征。
- 快速预览与标注采集分离；训练数据端支持来源发现、人工标注、明确负样本、完整性校验及按 run 隔离导出。
- LiDAR 扫描时刻与序号、无回波表达及 PointCloud2 格式转换；事件数据支持 EventCD 转换，事件默认启动采样。
- 桌面默认不启动 UE，支持窗口显隐和所属进程退出清理；完整分发工具统一为 Build-Distribution。

## 安装

需要 Windows x64、UE 5.8 C++ 工程、VS 2022 和 Python；本轮验证 UE 5.8.4。解压插件包，先保存并关闭宿主项目：

```powershell
python .\install.py --project 'D:\MyScene\MyScene.uproject' --map /Game/Maps/MyMap
python .\install.py --project 'D:\MyScene\MyScene.uproject' --map /Game/Maps/MyMap --apply
```

编译宿主 Editor，在地图中运行初始化脚本，使用同版完整源码仓库的桌面端连接。具体配置、初始化、资源兼容与自定义宿主启动见 [插件接入指南](../PLUGIN_DISTRIBUTION.md)。插件安装不会自动启动 Python 飞控。安装器暂不提供覆盖式原地升级，已有不同版本文件时先备份并在清洁宿主副本中接入。

## 已知限制

- 尚未在干净 Windows、其他 GPU 或自定义宿主完整 Cook 后实跑；不能将本机通过写成普遍兼容。
- 城市第三方 `M_Crowd_Head_v2` 的 Nanite 计算着色器 SRV 超限（65/64），存在回退材质；既有 Mass CustomData ensure 等未完全解决。
- 红外非辐射温度模型，固定翼参数未实机辨识；事件是帧驱动近似、LiDAR 是理想射线采样，不等同真实厂商接口/RAW。云台同刻双光不等于像素配准；航拍数据需人工标注，尚无自动 GT。
- 没有在线更新器或签名安装器。完整城市资源、引擎、Python 环境、UserData、构建缓存和未发表论文草稿不作为本轮源码提交/插件附件内容。

保留上游许可证；第三方城市、模型和数据各自的许可不由本项目代码许可替代。完整包对外提供前另行核查相关资产分发条款。
