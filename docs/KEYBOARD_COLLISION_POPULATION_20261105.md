# 操作、窗口、固定翼和人群更新

云台观测操作栏隐藏相机入口；航拍上下左右键控制抬头/低头/左右转，100ms重复步进，松键停止。输入框内编辑不接管，切任务、失焦和断连清除按键。原WASD/RF/QE驾驶保留。

正式桌面入口默认最大化；场景设置中的全屏显示和F11切换全屏，退出全屏回到最大化。只需重启桌面。

固定翼原来中心线检测命中后停止，容易漏检机翼，且停止后继续按钮无法实际恢复。改成依据模型尺寸/缩放/姿态的机体盒扫掠，触碰后清零操控和实测速率，保留最后安全姿态；停止后拒绝假恢复，界面显示碰撞保护及返回起点入口。仍为保护停止，不是六自由度刚体接触、坠毁或地面起降模型。原生编译通过，本轮未实测主动撞墙，不能声称全部碰撞/姿态问题已修复。

被动行人显示默认使用原有VAT动画实例，取消近处高/中精度骨骼Actor预算，减少相机看见行人时的角色创建和动画成本。车辆首次加载造成的停顿未全部解决。密度100%预算由300/300/600增到600行驶/600停放/1200行人，原百分比保留；不是保证同屏数量。原始城市资产不改。

22项界面测试（任务栏、按键生命周期、全屏、原布局与双语回归）通过，UE Editor编译通过；隔离小城航拍源帧/连续朝向/驾驶独立实跑通过，10%预算60/60/120，资源就绪和增加航拍采集的快照约28.7/30.0 UE FPS。不是同场景A/B基准，也不是持续不卡保证。所属会话已退出，未起飞；日常数据未写入。证据见evidence/keyboard-collision-population-20261105。

航拍常见载荷可包括可见光、红外热像、多光谱、激光雷达。当前机载仍只有可见光；可接入独立机载红外，需新增捕获/内参/安装外参及机载视角的热像处理，不能直接复制云台帧。地面人车当前没有热材质和2D GT的完整标定，不能宣称已支持真实温度或已完成机载红外。该项本轮为可行性答复，尚未实现。
