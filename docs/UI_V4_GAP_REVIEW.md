## 本轮已补齐

| 原差距 | 本轮实际改动 |
|---|---|
| 设备页还是旧十列编辑表 | 实例列表＋所选设备详情；名称、型号、XYZ、偏航、目标仍写入同一设备草稿，复用新增／复制／删除／保存／加载逻辑。列表坐标显示两位小数，名称编辑不截断原坐标 |
| 硬件信息占两行且很长 | 摘要移至设备栏，完整实际指标从“诊断”打开；侧栏隐藏时顶部仍有诊断入口 |
| 输入归属藏在提示里 | 画面上方持续显示键盘、驾驶实例、云台控制实例；选择属性仍不接管 |
| 起降跟长表单滚走 | 起飞／悬停／降落及状态固定在右栏上方；屏幕按键、精确云台角度、RPM 详情按需打开小窗 |
| 启停按钮挤在一行 | VIS／IR／LiDAR 分行显示，明确开启／停止采集，保留真实确认和参数草稿 |
| 训练图像工具过大 | 缩放、适应、1:1、放大改为紧凑底部工具，与尺寸／GT／帧号同栏；底部显示真实会话／设备／组身份 |
| 训练策略无层次 | 保留常用速率与目录，标注策略按需展开；接收与保存语义不变 |
| 设置仅三个旧分组 | 补为连接与会话、性能与画质、存储工作区、窗口布局、场景与版本；画质回读同一档位，输出使用实际 DATA_ROOT |
| 接口缺少 GT／飞控分区 | 增加独立分区、配置地址及文档入口；GT 明确未探测，不拿 UE 连接状态冒充数据服务可用 |

## 默认只启动系统界面

根 `Start-WISEYE-Studio.vbs` 改调 `scripts/Start-Desktop.ps1`，不传 `--connect`，不自动启动 UE／飞控。点击“启动仿真”才创建 RuntimeManager；已有仿真从资源设置连接，仍保留外部会话所有权。

源码桌面沿用现有 `E:\Projects\WISEYE-IR-Work\preview-data` 配置（目录存在时）；显式 `-DataDirectory` 或 `WISEYE_DATA_DIR` 优先，没有该目录时使用源码配置即可打开 GUI，无需 UE。`Start-SimulationPreview.ps1` 保留为显式开发预览工具。

实际执行根 VBS，出现可见 WISEYE 主窗口，新增仅两层 venv pythonw，无 UnrealEditor，50051／50052／50100 无监听，测试后关闭。见 [启动记录](evidence/ui-v4-20261030/refinement/desktop-only-start.json)。
