## 仿真端

- 左侧固定导航：工作台、场景编排、设备管理、数据接口、资源设置。内部仍保留原页面索引，避免旧回调指向错误页面。
- 工作台默认场景主画面与底部传感器缩略窗，保留已有布局切换、换源、放大及布局恢复。左侧设备树、右侧上下文控制；单击属性不接管驾驶。原有布局偏好可以保留，点击“恢复布局”回到默认布局。
- 无人机／云台切换、驾驶与云台实例选择、起降、真实 RPM、遥杆、跟踪／保持均复用原有控制对象。参数按钮或选中传感器打开右侧参数停靠栏，可关闭或浮动。
- 参数侧栏明确设备和传感器身份；常用参数直接显示，增益与探测器高级参数、安装与双相机几何折叠。待应用草稿、待回包与实际回读状态仍分开；各设备独立。支持实时启停的服务通过云台面板的快捷开关操作，避免重复的启用字段。
- 场景编排为“设备列表＋真实 UE 观察画面＋所选设备位姿”。观察画面复用工作台同一来源，进入该页不会多建观察采集客户端。点击“接管自由观察”后可控制观察视角；选择设备后用“到 UE 预览放置”查看完整模型。
- 设备管理改为常驻页面，仍复用现有设备编辑、验证、保存、加载逻辑。重新读取或退出会确认未保存草稿；保存设备配置与实际重新加载仍分开。
- 航线编辑采用左侧 XY 画布、右侧航点表，草稿操作与上传／执行分组。此处仍是实际 XY 编辑器，尚无 UE 三维航线叠加。
- 数据接口保留实际地址与协议入口；资源设置改为分类列表与内容区。没有创建无后端的服务状态或训练任务页面。

## 训练采集端

- 顶部保留数据连接状态、连接设置和连接／断开；采集条集中显示实测预览 FPS、保存组速率、计数与开始／停止保存。
- VIS/IR 为并排主画面，保持原始宽高比、缩放／适应／1:1／独立放大功能。融合缩为底部缩略窗，通过“展开融合”打开原有实时窗口。
- 右侧统一放置数据源、预览／保存上限、目录、标注策略、融合参数。连接设置弹窗可编辑主机／端口／云台后应用；连接中在线策略、目录和换源逻辑保持。
- 保存只有准备、实际保存、停止、异常等真实状态。未收到有效样本不会冒充已保存；停止保存保留接收器，继续预览。
- 使用原 Receiver、单槽最新帧与解码结果，不增加第二套采样。GT 开关只影响预览叠框；同组原图、标签、元数据仍保存到原 `visible/IR/{images,labels,annotations}` 目录。
- 两路独立光心及视轴差、融合旋转补偿语义不变；当前没有模型训练执行器，名称“训练端”仍指现有数据与融合工作台。

## 已知限制和后续

1. 测试从相对楼顶较高的位置直接执行 Land 时，遇到 AirSim `Land` 的 60 秒 NNG 响应超时，飞控服务随后重连。最终 UI 验收先手动下降至起点附近约 2m 再降落，未修改飞控后端。**高位直接降落问题尚未修复**；不能把最终通过解释为任意高度关闭都保证降落成功。
2. 默认预览上限 5、保存上限 1，允许 0.1–10；当前实测仍约 4–5 组/s，本轮未提高渲染／读回吞吐。4.68 与之前 4.51 的差别不构成性能优化结论。未完成完整 GUI CPU／内存与长时多机负载对照。
3. 小屏下使用滚动参数栏和可拖动分隔条；未为 1440×900、150% 缩放提供完整适配。
4. P2 样本只读浏览／检查器、真实三维航线叠加、进一步拖拽编排尚未实施。融合三路常驻偏好等方案细项也没有作为本轮已完成能力。
5. 未重新 Cook／打包，未提交／推送；旧独立运行包不会随源码 UI 改动自动更新。未修改本轮 UE/C++、地图、Fleet、模型或红外成像。

启动方式不变：双击根目录 `Start-WISEYE-Studio.vbs`，右上角打开训练端。已有 UE 时只打开桌面可执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\WISEYE-Studio\scripts\Start-Desktop.ps1" -Connect
```

真实联调脚本会起飞并关闭自己启动的预览，只应在没有其他 AI 或用户占用测试 UE 时执行。失败会保留报告，不能用失败目录冒充最终验收。
