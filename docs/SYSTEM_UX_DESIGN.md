# WISEYE 系统产品与操作流程设计

> 2026-10-19：用户提出主系统聚焦仿真与开放接口，算法/复杂分析由扩展应用完成。新的[仿真平台设计 V2](WISEYE_SIMULATION_PLATFORM_DESIGN_V2.md)已获用户批准，正按 A/B/C/D 实施；本文原有算法闭环方案保留为前序设计，不作为继续开发算法页面的授权。

## 1. 系统定位

WISEYE 是“场景—载机—传感器—算法—实验结果”闭环的无人机多模态仿真工作台。UE 负责场景、渲染、云台和传感器；Project AirSim 负责飞行动力学与飞控；桌面端负责任务配置、实时操作、算法运行和结果回放。

场景、机型和传感器是可换资源，飞行、云台、数据和算法流程是可复用能力。

## 2. 信息架构

1. **首页 / 系统检查**：显示 UE、AirSim、RTSP、GPU、地图和算法环境是否就绪，并给出可执行的修复操作。
2. **任务配置**：选地图、无人机型号、传感器组合、起飞点、航线、环境和实验名称。
3. **实时作业**：中心显示 CH1/CH2 与点云，右侧提供起飞、悬停、降落、航线/手动、机型、云台、相机和激光控制。
4. **算法与自动指向**：选模型、输入通道和置信度，显示检测框、跟踪 ID、延迟和目标丢失。
5. **数据与回放**：同步查看视频、点云、飞行位姿、云台角度、检测结果和事件，支持标记、导出和重现。
6. **资源管理**：管理地图、机型、传感器标定、算法版本和标准场景包；Fab/社区场景通过 UE 安装后注册。

## 3. 完整任务流程

### 创建

1. 新建实验，填写名称和目标。
2. 选择已安装地图；新地图先完成资源安装、设备放置和遮挡检查。
3. 选择无人机外观与飞行配置。外观切换不改变 AirSim 位姿真值；重量、惯量和电机参数由独立的动力学配置决定。
4. 勾选可见光、红外、激光雷达、深度、事件相机或雷达，并显示带宽/算力预算。
5. 设置起飞点、航点、高度、速度、循环次数和云台初始状态。

### 启动前检查

启动后自动检查：地图已加载、无人机无穿插、AirSim 位姿链接、云台轴向正确、CH1/CH2 出帧、激光有效、存储足够。失败时停在当前步骤，不允许在无画面时起飞。

### 作业

默认先悬停，再选“执行航线”或“手动飞行”。起飞、降落和场景切换是独立按钮；方向按钮只在手动模式可用。地图切换、AirSim 断开或 RTSP 中断时，界面立即显示原因并禁用不可用操作。

工作区始终显示三个指标：飞行控制权归属、数据是否新鲜、实验是否正在记录。

### 结束与复现

标准结束流程是“悬停→降落→停止记录→生成报告”。报告保存地图 ID/哈希、机型及动力学配置、传感器参数、算法版本、时间轴、告警、输出位置和验收结果。重现会创建新实验，不覆盖原数据。

## 4. 状态与控制权

| 状态 | 允许操作 |
| --- | --- |
| 未连接 | 选资源、编辑任务、启动服务 |
| 就绪/已降落 | 切地图、切机型、标定、起飞 |
| 起飞中/降落中 | 悬停请求、查看状态 |
| 悬停 | 自动/手动、云台、传感器、降落 |
| 自动航线 | 悬停、云台/传感器、任务中止 |
| 手动飞行 | 方向/高度/航向、悬停、降落 |
| 故障 | 保存诊断、重连；能控飞时优先悬停/降落 |

相机中断不等于飞控中断，两者要分开显示。已失效的位姿、图像或点云保留最后一帧时，要覆盖“已过期”和最后时间。

## 5. 数据和接口

- 图像：CH1 可见光、CH2 红外，RTSP/H.264；元数据包含仿真时间、帧号、内外参和云台位姿。
- 点云：预览使用有界 JSON，算法/录制使用二进制帧，离线导出 PLY/PCD。
- 飞行：AirSim 是唯一位姿和动力学写入者；桌面端通过 50052 发高层指令。
- 场景：使用 `scene_id` 和标准装配注册，不在通用算法中写场景特有 Actor 名称。
- 型号：`model_id` 和 `dynamics_profile_id` 分离，防止外观与飞行参数混淆。
- 实验：所有数据共用 `experiment_id` 和单调时间轴，记录丢帧、延迟和时钟偏差。

## 6. 实施路线和验收

### A. 当前可用基线

已有多地图、AirSim 动力学、云台可见光/红外、云台激光、CH1/CH2 RTSP、起飞/悬停/降落接口、手动/自动飞行和 Mavic 3/Avata 外观切换。

### B. 数据面优化

使用异步 GPU readback，实现 CH1 15 FPS/CH2 25 FPS；为图像、点云和飞行增加统一时间戳、队列深度、丢帧和延迟。连续运行 30 分钟，飞控不被视频阻塞。

### C. 任务编辑和记录

实现航点编辑、起飞前检查、实验一键记录、统一目录和回放器。在两张地图、两种机型上重现同一任务。

### D. 多模态和算法闭环

按“深度→雷达→事件相机”顺序接入。每个传感器都定义参数、坐标系、时间戳、噪声模型、导出格式和验收场景。然后接单帧检测、异步跟踪和云台视觉闭环。

### E. 交付

建立一键安装检查、打包配置、故障导出和自动验收报告。新电脑按文档在 30 分钟内进入第一次实时任务，作为最终易用性验收标准。
