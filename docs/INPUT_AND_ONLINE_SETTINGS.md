# 2026-10-29 持续操控、放置长按与训练在线设置

后续训练预览已合并：不再需要切换视频/标注样本模式，GT框仅控制叠加；当前帧率与实测见[统一预览](GT_RATE_AND_UNIFIED_PREVIEW.md)。下文双模式操作说明仅保留历史背景，输入队列与长按修复仍有效。

桌面AirSimClient对每个设备只保留一个已发出的flight.set_input和一个最新待发输入。长按期间的重复输入合并，松键的全零输入覆盖旧移动值；收到确认后发送最新值。降落、悬停、模式切换等动作清掉待发移动，断连或错误清理旧队列。不会在长时间按键后逐条重放历史方向。

飞控后台的手动速度/制动使用AirSim现有SingleTaskCall替换上一个任务，不再为每次输入同步调用CancelLastTask，再发送速度。输入不改变模式/暂停状态，因此也不再每Tick额外同步flight.sync_state到UE。Fleet返回复用已读取的当前设备遥测，避免同一次输入重复读取；其他设备仍独立。其他起降/航线命令保持原任务取消逻辑。

UE放置WASD/QE/RF保留点按10cm/1°、Shift1cm/0.1°。每个键独立计时，按住0.3秒后以最高10Hz连续微调，松键立即停止；时间基准为墙钟，慢帧后不补执行积压步数。WASD仍按当前设备朝向，首次微调自动锁定，确认后才应用真实设备。

训练端不再因连接而锁住策略、目录或数据源：

- 遮挡/出画策略、保存目录在线更新，接收线程以版本快照应用到后续新采集样本；设置改变时丢弃仍在途的旧策略帧，避免按旧策略保存到新目录。已开始写入的一组会完成原目录提交。
- VIS/IR勾选自动异步停止旧订阅并重新订阅，用户不需点断开；切换期间清空旧画面，不混用旧GT。至少保留一路。
- 主机、端口、云台ID可以编辑，点击原连接按钮（连接中显示“应用连接设置”）后自动重连，保留当前采样/保存选项。
- 显示/保存FPS、录制开关、缩放继续在线可调。GT与融合控制需要“同步标注样本”视图；实时视频仍不叠加旧GT。

线程停止使用非阻塞轮询收尾，接收中修改设置不在GUI线程进行网络RPC。没有提高UE同步GT的2FPS上限，也没有向训练网关增加飞控权限。
