# 工作台交互与天气改进

2026-11-02，覆盖大小城市共用桌面和原生代码。源代码在F，原生模块同步并编译到E衍生工程；不修改用户Scene/Fleet/Layout。

## 两个主要会话按钮

右上保留“启动仿真／关闭仿真”和连接状态按钮。“已连接·断开”点击后只断开桌面与飞控连接，不关闭UE；再次点击“未连接·连接”恢复。连接中的按钮可取消。关闭本次启动的仿真时清除持续操控输入，异步执行既有安全降落与进程清理；关闭期间禁重复启动，完成后恢复启动按钮。手动连接的外部UE不按本次所属进程强制关闭。

同时修复关闭时沿用启动旧run_id的问题：换地图后，退出清理先读取所属UE当前会话，再执行land_owned_fleet。默认仍不自动启动UE。资源设置页只保留地址/端口编辑与状态说明，不重复显示一排启动/连接按钮。

键盘模式及驾驶/云台归属从画面区移到右侧操作栏。点击传感器树或预览标题不自动弹出参数，明确点右侧“参数”或画面菜单“编辑此传感器参数”才打开。

## 图像查看

滚轮在1–16倍范围内改变显示倍率，以指针位置为锚点；放大后左键平移，双击复位。ObserverInput原有右键观察场景操作保留。弹窗图标直接放在每个工作台画面放大图标旁，弹出后仍共享同一来源客户端。原像素菜单保留。

缩放只在画面绘制阶段完成，不改UE镜头视场、源帧尺寸、标注或保存数据；不会分配一张16倍尺寸的新图像。低分辨率红外放大仍不会增加真实细节。

## 运行评估

诊断和左下摘要显示未评估／评估中／准备中／良好／一般／较差／数据过期。取最多8个新硬件样本的中位数，至少3个才评级；资源编译中不把加载帧率当作稳定性能。连续5秒没有新硬件样本则提示数据过期。

相对当前30/45/60FPS上限，低于80%为一般、低于50%为较差；显存预算使用达到85%／97%、系统内存达到90%／97%也会降低评估。单独GPU高利用率不会判差。它是当前负载下的运行评估，不是硬件等级、训练帧率或全城保证。

## 雨、雾与夜间

此前全局Rain参数和天气Actor存在，不代表雨粒子真的产生。本轮只让Native管理本地相机雨体积，停用其Blueprint跟随Tick；显式更新RainDensity与激活状态，关闭不用的雪/叶/尘组件。原始发射器可能产生十几万粒子，已限制本地密度，减少无谓开销。environment增加rain_active_particles，设置页区分雨量已设置与雨效运行中。可见光雨粒子不混入红外热代理，不声称已经实现真实LWIR降雨散射。

大雾会沿距离降低透射与对比度，因此远处无人机更难辨认；这不是镜头失焦。近处几米物体受影响可能很小，不能用一张近景判断远景雾效。当前是UE指数高度雾，尚未标定实际能见度；GT仍采用几何可见性，不自动按雾导致的低对比删除标注。

夜间此前只有太阳/天光调整，自动曝光容易把暗场抬亮，原城市白天天幕也可能还显示。本轮深夜隐藏识别到的SM_dome/SM_sun，恢复白天时还原可见性；对可见光、观察视角施加夜间曝光约束及暗部增益，红外读出不套用可见光曝光。导航灯自发光从64降至6，夜间Bloom从0.08降至0.015，减小光晕。

无照明、远距离或目标只有几个像素时，可见光仍可能只看到航灯，不能保证机身轮廓可辨；可改用红外或靠近/调整光学视场。本轮没有给机身强行加发光，也不是低照度传感器噪声或月光的物理标定。
