# WISEYE 使用指南 · v1.1.0

## 启动与关闭

完整包全部解压后运行 `WISEYE/WISEYE.exe`；源码环境双击根目录 `Start-WISEYE-Studio.vbs`，或执行 `scripts/Start-Desktop.ps1`。打开界面只启动桌面，不默认打开 UE。

在“场景编排”选择小城市或大城市试验场景，再点击右上角“启动仿真”。等待场景、飞控和传感器就绪后操作，不要在加载中重复启动。右上角连接按钮用于连接/断开；“启动/关闭仿真”管理本次启动的进程。网络已连接不代表 UE 仍正常推进，异常请查看左下诊断。

关闭前让多旋翼降落、停止固定翼飞行并停止采集，再关闭仿真。桌面退出会清理自己启动的关联进程；不要依靠强杀代替正常结束。运行与配置需要可写目录，便携包使用旁边 UserData，源码入口也可显式指定数据目录。

本轮完整运行包包含大小城市，可脱离源码和 Scene 目录运行。源码 SDK 只包含插件、设备和传感器资源，不含城市或完整桌面环境。下载及依赖见[安装指南](INSTALLATION.md)。

## 场景与设备

编排页管理设备初始位置和型号，可在 UE 里预览模型放置；先选择对象，再到 UE 自由观察找到表面位置，跟随指针的模型用于确认落点，按界面提示确认/取消。设备以米显示坐标，UE 内部采用厘米；不要把模型预览点当相机光心。

“应用当前场景”与“保存初始配置”是两个动作：实时新增/修改设备不必重载地图，保存初始设置用于下次加载。移动、跨类型修改或删除前，先停止受影响飞机；换地图会重建运行会话。已有用户布局不应被历史默认配置覆盖。细节见[实时设备管理](LIVE_DEVICES_20261105.md)。

默认小城市适合日常验证；大城市是独立流送的试验地图，只有加载它才使用其运行场景，部分城市公共资产仍共享。短时测试通过不代表全城、多机或长时稳定性能；大城首次加载和缓存准备可能明显更慢。

## 无人机和观察视角

先明确“驾驶对象”，再选择手动、航线或巡航。云台控制对象和画面来源独立，点击其他画面不会自动接管那架飞机。手动控制需将键盘归属切到驾驶对象并确保窗口焦点；松键或失焦应停止持续输入。

| 键盘驾驶 | 功能 |
|---|---|
| W/S、A/D | 前后/左右驾驶输入，固定翼解释为增稳目标 |
| R/F | 上升/下降；固定翼为爬升目标输入 |
| Q/E | 转向输入，具体响应随机型/驾驶模式变化 |

起飞、降落、接管和停止优先使用当前驾驶对象的界面按钮。固定翼采用 JSBSim 参考气动及空中初始化，不具备已标定的跑道起降；它需要速度和转弯半径，不能像多旋翼原地悬停。参考参数未经过实机辨识。

自由观察采用右键加 WASD/QE 导航，与飞行键盘归属分开；观察镜头变化不会移动设备。画面支持滚轮缩放、拖动平移、适应窗口、弹出和全屏。UE 窗口可弹出/收回，隐藏后仍需渲染，并不节省全部 GPU 资源。

## 云台与坐标

选择云台后，用右侧遥杆、分配给云台的键盘控制或角度/坐标接口转动；跟随模式使用目标真实坐标，保持模式固定当前方向。它不是视觉检测闭环跟踪。

实时遥测显示实际方位/俯仰、双镜头视场角、目标距离和设备位置。未设置真实测绘基准时，City Sample 不带可信的真实经纬度。可设置自定义仿真基准（参考经纬高、UE 原点和北向）后换算坐标；显示的地理值仍是模拟参考，不能当实测海拔。见[云台坐标与设备数值](GIMBAL_COORDINATES.md)、[接口](GIMBAL_INTERFACE.md)。

## 传感器与成像

每个设备的可见光、红外、事件和 LiDAR 参数单独设置，开启/停止只影响对应采集，保留飞控和控制连接。画面卡片固定绑定设备/传感器，不随驾驶对象自动改变。机载可见光和红外可并排显示。

- 可见光为 1920×1080；可调模糊、噪声、对比、饱和度及 auto/manual/infinity/off 对焦、距离和光圈。景深是光学近似，自动对焦不是完整实机算法；过度模糊会丢失小目标。
- 红外为独立光心 640×512，可调视轴偏差、视场、极性和热外观参数。建筑、道路、天空与目标局部热特征采用近似，不是温度/辐射模型。可使用稳定背景亮度或锁定范围，避免增益变化误解为温度突变。
- 事件为约 15 Hz 帧驱动的亮度变化近似，存在插值和截断，不是微秒硬件传感器。
- LiDAR 默认可从云台视角查看，也可自由旋转；其数据是理想射线扫描，带时刻/序号与无回波表达，不是完整扫描畸变/多回波模型。

内部快速预览取最新完成帧，RTSP 是独立外部数据接口，不必为内部显示增加视频编解码往返。RTSP 和其他接口参数可编辑；原始事件和点云不通过 RTSP 传输。格式适配及边界见[传感器说明](SENSOR_UPGRADE_20261109.md)、[协议](PROTOCOL.md)。

## 天气、画质与性能

环境、时间、雾、雨、人车密度和画质从场景菜单进入。可见光会受夜间曝光、雾和雨影响；无照明的远距无人机轮廓可能消失，导航灯可能更突出。当前天气是工程近似，不能用滑块值当实测能见度或降雨量。

GPU 高占用时降低画质、人车密度或采集频率，关闭不需要的传感器和额外视图。诊断中的良好/较差评估基于当前数据及资源准备状态，设置 30 FPS 不等于实际输出 30 FPS。云台/航拍双路、高密度人车及大城会增加负载。

## 训练数据工作台

从仿真端打开训练端，或运行完整包的 `Training/WISEYE-Training.exe`、源码 `training_client/Start-Training.vbs`。快速预览与标注采集分开，快速预览不提供逐帧同步 GT；需要保存和标注时进入相应采集流程。

云台可采同 Tick 双光及各自投影标注；独立光心意味着不能保证像素配准。航拍双光当前保存待人工标注原图，必须完成框或明确负样本审核，不允许将待审核图自动当负样本。保存、校验、标注及数据集导出见[训练端指南](../training_client/README.md)。

## 更新、迁移与故障定位

唯一源码工程位于仓库 ue5/WISEYE；本机两个旧外部工程已隔离，不再使用 IR-Work/Evaluation 旧路径。城市源码构建仍需原始 City Sample 资源，普通完整运行包不需要。见[目录依赖](PROJECT_DEPENDENCIES.md)。

更新前备份 UserData、保存源码改动并关闭程序。源码用 `git pull --ff-only`；原生/资源改动需要相应重建。完整包解压到新目录，保留兼容用户数据；当前没有在线更新器。插件升级会拒绝冲突文件，先备份宿主并预检，不要覆盖原工程。见[打包和升级](RELEASE_BUILD.md)。

连接正常但画面停住时检查 UE 是否推进、传感器是否开启、是否处于加载以及磁盘/GPU 状态；训练吞吐较低时分开检查源捕获、GT 采集、网络和保存速度，不把快速预览速率当标注吞吐。错误排查应提供当前版本、场景和相关日志，避免引用旧包测试结论。
