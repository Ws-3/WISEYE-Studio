# 人群渲染设置、运行提示与实时航拍朝向（2026-11-05）

补齐CitySample原始人群骨骼资产要求的四项项目设置：`r.GPUSkin.Support16BitBoneIndex=True`、`r.GPUSkin.UnlimitedBoneInfluences=True`、`r.SkinCache.DefaultBehavior=0`、`SkeletalMesh.UseExperimentalChunking=1`。配置写入源码及本机预览工程的DefaultEngine.ini，与原始CitySample配置一致；UE实际启动日志确认读入。需要重启UE，首次会重建部分骨骼网格和缓存。没有通过隐藏通知绕过资产要求。

运行评估与建议现在共用资源准备状态：资源编译、地图流送未完成或人车生成未完成时，显示“场景资源正在准备，完成后再评估帧率”，不累计“持续低帧率”告警。资源就绪后重新收集独立样本，连续低帧率仍如实提示；显存和内存压力建议继续保留。不是把加载中的4.5FPS改成虚假的正常值。

场景 → 无人机航拍新增“抬头、低头、左转、右转”按钮，单次2°，长按300ms后每100ms重复。默认勾选“实时应用相机朝向”，方向按钮及俯仰/朝向数值修改后自动生效；取消勾选则点击“应用”。相对机头转向±180°、俯仰−90°至20°；相机方向调整不切换驾驶对象。保存为本场景默认仍为显式操作。

实时请求有80ms合并窗口，最多一个配置请求在途、只保留最新朝向；旧ACK不能覆盖等待发送的新角度。配置在途时方向控件保持可操作，其他配置字段等待确认；断连、换机、换场景和关闭窗口停止自动发送。未确认或失败时保留提示，不无限重试。窗口使用现有主题和中英文目录。

20项相关测试通过，包括资源准备期间不累计低帧率、加载后重新计数、连续输入在途合并、旧确认不覆盖最新角度、断连和关闭取消队列、手动模式及既有界面回归。隔离小城实际运行：uav-02机载图像俯仰−30°→−75°，长按右转到10°，原始图像随之变化，驾驶选择保持；测试没有发起起飞，所属会话全部退出，日常UserData未写入。

本机B580/14600KF单次状态快照：资源就绪时约25.4 UE FPS，增加1920×1080、15Hz航拍预览后约18.1 FPS，VRAM约4.3→4.5GiB。不是持续基准测试，不能据此宣称优化到30FPS。采集额外视角仍消耗GPU；需要更流畅时可降低航拍采样上限、人车密度或其他传感器采样。当前改动修复资源兼容和加载期误导提示，未替换渲染方案或降低源分辨率。
