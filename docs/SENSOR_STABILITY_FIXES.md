# 大小城市传感器与成像稳定性修复

2026-10-31，覆盖 `city` 和 `city_large` 的共用代码。F盘维护源码，原生模块同步并编译到E盘衍生工程。保留用户Scene/Fleet、双相机外参、当前红外材质与目标热斑，不修改原始CitySample地图。

## 采集开关与控制连接

原缺陷：关闭当前显示的相机后，GetSensorTarget返回空，状态报告width/height=0；桌面把它判成非法分辨率并断开控制连接。

现在状态始终返回该相机规格；enabled单独表明是否采集。桌面兼容旧后端的0×0停用状态，但必须有该相机明确的enabled=false，不放宽到任意坏状态。停止采集不停止UE、飞控或观察画面；再次开启仍沿用参数。全部传感器关闭后应看到采集/扫描序号停止增长，UE tick与OBS继续推进。已在UI开关旁明确说明。

## 雨效资源生命周期

天气Blueprint类原来有强引用，但天气参数Collection资产未保留，参数实例也是弱引用。运行中的GC可能让天气能力由可用变为不可用，而EnvironmentInitialized阻止重新加载。

现在类、Collection资产及参数实例均保留UPROPERTY引用；独立资源检查支持失效后每2秒重试，不重复记录原环境基准，也不重新扫描所有灯光。状态增加rain_unavailable_reason，雨量控件提示实际不可用原因。仍为已有天气粒子的视觉效果，不包含地面湿润、降雨动力或真实红外雨衰模型。

## 红外背景稳定

稳定自动增益现在排除天空和目标，只使用足够数量的背景像素；已初始化后背景不足时保持上次范围，不切回另一组全画面统计。窗口变化限速从每秒0.15归一化信号降低为0.025。

为避免单一墙面成为自身黑点，稳定自动模式至少包含归一化参考区间0.10–0.36。这是当前代理热信号的工程范围，不是温度或标定辐射值。保留已有楼宇灰度曲线、白热/黑热、目标电机/电池细节及光学模糊，不增加新的成像版本。锁定和手动增益不套用该参考范围。

操作：云台→红外参数→增益与探测器高级参数，启用“稳定背景亮度”；需要跨角度固定灰度时选择“锁定当前范围”。自动模式仍可能缓慢适应真实画面内容；此修复不等于整城热物理校准，也不保证所有LOD/热分类切换已消除。

## 点云与清晰度

- 点云默认“云台视角”：雷达本地原点向前的透视投影，光轴居中、按实际扫描视场绘制，保持角度比例，不随回波包围盒自动居中。背后的点不投影。点云不与可见光冒充逐像素配准。
- 下拉切“自由三维”可拖动旋转；保留正视/俯视和滚轮缩放，双击回云台视角。空回波仍显示真实空帧，不补造点。
- 本地异步JPEG缓存质量从60提高为90，VIS仍1920×1080、IR仍640×512、OBS仍960×540。camera.stream_frame返回实际quality=90；quality请求字段仍兼容校验，当前缓存统一编码，并非逐请求独立编码。
- 画面右上“···→1:1 原始像素（可滚动）”可排除缩放影响。该功能原已存在，本轮明确入口名称。红外光学模糊与背景柔化保留，640×512放大也不会凭空增加细节。提高JPEG质量可能增加编码/传输成本，不能当作帧率提升。

## 验证

Editor原生模块构建通过；108项核心测试、31项相关Qt测试及直接编译运行的tests/native/test_thermal_math.cpp通过。涵盖旧版0×0停用回复不触发桌面断连、损坏状态仍拒绝、点云光轴/视场/距离比例、背景不足保持增益、相同墙面在不同天空占比下统计一致等。

真实“小城市→大城市→小城市”通过：每个场景8次可见光/红外启停ACK，再检查三类传感器全部关闭时采集/扫描序号停止、UE tick和OBS继续，桌面UE与飞控连接均保持。雨量70%时两处视角雨效Actor建立，停止后归零；返回小城市雨效能力仍为true。大小城市的全天空连续样本都保持增益范围，锁定模式转角后上下限不变；回到同一建筑视角，图像灰度中位差分别为5/255和1/255（含噪声/场景渲染差异），不把这种数值当作真实红外标定精度。

本轮末次硬件快照：小城市约30FPS/UE内存8.88GiB/UE显存4.00GiB，大城市约30FPS/12.21GiB/4.13GiB；仅是此次末次样本，不是长时或端到端预览帧率基准。JPEG90原尺寸图像有效，未测训练吞吐与外部RTSP延迟。
