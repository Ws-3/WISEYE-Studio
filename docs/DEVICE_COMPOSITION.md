# 型号、实例与挂载关系（2026-10-21）

## 多实例首轮已实现

用户要求开始多设备实现后，已加入 `core/devices.py` 型号注册表与场景实例配置，UE `WiseEyeFleet.cpp` 运行时复制经标定的装配；不改 Content 地图/模型资源。当前注册 Mavic 3、Avata、80 cm 云台；无人机与云台可分别新增/复制/修改名称、型号、起始位置和偏航，云台可选跟踪无人机。最多每类 4 个，默认 uav-01 / ptz-01 为兼容入口保留，不能删除。

配置在 `ue5/WISEYE/Config/WISEYE/Fleets/<scene>.json`，保存后重新加载场景生效；原始场景当前提供两架无人机、两套云台，重启待命。不存在该文件时兼容原有单机布局。多实例配置优先于旧 Layouts；编排页旧坐标只针对默认实例，保存时同步到多实例配置。旧命名位置预设仍只含默认实例，多设备整体配置以 Fleets 文件为准。

UE 桥接通过 device_id 找到相应实例，未知/错类型 ID 拒绝；云台参数、旋翼和导出不共用状态，跟踪目标可跨实例选择。飞控创建真正的 Drone1/Drone2 等独立 AirSim Robot，每机独立 FlightController、航线快照与任务。桌面驾驶对象和云台对象分开选择；切换时清零旧输入，过滤过期对象状态，传感器草稿按云台隔离。总览当前显示所选云台的传感器，所有云台的数据接口仍同时发布。

传感器 ID 使用 `<ptz-id>/visible|infrared|lidar`，原始导出伴随设备/传感器/场景/会话标识。ptz-01 保留 CH1/CH2 地址，额外云台分别为 `rtsp://127.0.0.1:8554/ptz-02/CH1`、`.../CH2`。OBS 为全局观察相机。此阶段保持原生可见光 1920×1080、红外 640×512。

边界：新增/删除不是飞行中热插拔；目前不能通过界面导入任意新型号，Mavic/Avata 仍共用四旋翼物理参数，不是厂商独立标定。传感器参数/启停、运行时跟踪选择仍为会话设置，持久配置目前含型号、位置、偏航和默认跟踪目标。实际验证以双机双云台为基线，4+4 性能、避碰、队形、编队统一任务和全设备同时画面布局尚未验收。

下面保留本轮实施前的设计记录，旧的“固定单实例”描述已由以上实现更新取代。

本文记录面向多设备的设计边界，不表示以下注册与新增功能已经实现。

当前：一套 AWiseEyeDemo 云台装配、一个 AirSim Drone1；协议/桌面仍固定 ptz-01、uav-01。Mavic/Avata 切换的是外观，共享 AirSim 动力学，并非两种已分别标定的整机物理模型。现有整体位置、旋翼、云台层级可控制，但还没有通用型号注册、实例新增、复制或删除。

后续按三个层次组织：

| 层次 | 保存内容 | 修改范围 |
| --- | --- | --- |
| 型号模板 model_id | 模型与尺寸、部件层级、关节限制、动力学配置引用、默认挂载槽、传感器默认能力 | 编辑模板后显式更新所选实例；不自动改正在飞行的实例 |
| 场景实例 device_id | 型号引用、初始位姿、实例参数、启用状态、任务与所属场景 | 同型号不同实例分别编辑和控制，复制时生成新 ID |
| 挂载 sensor_id | 传感器类型、parent_device_id、parent_link/mount、安装变换、独立参数、输出端点 | 随父设备或云台关节运动，可选按默认组合整体创建 |

云台实例是一整套固定底座、偏航轴、俯仰轴及传感器安装位；无人机实例是一整套机体、旋翼、动力学实体及机载挂载。界面选中整体可以移动、复制和配置；进入子项可调整传感器参数。模板默认值与实例覆盖值分开，删除实例时明确列出从属传感器和任务。

迁移顺序：先设备注册表与数组式场景配置 → UE 根据实例生成装配 → 每机独立 AirSim Robot/飞控上下文 → 命令携带 device_id、sensor_id → 状态/任务/原始记录按 ID 分流 → RTSP 端点按实例分配 → 两套云台与两架无人机交叉隔离验证。保留现有单机协议兼容入口，不能仅在设备树多加几行就宣称多机。

新增整型号还应覆盖模型资源依赖、坐标/尺寸、动力学与安装标定；导入 Mesh 本身不等于新增了可运行的完整型号。传感器接口统一携带仿真时间戳、坐标系、父对象和外参，便于后续独立扩展应用处理。

Project AirSim 可配置 camera、lidar、radar、imu、gps、barometer、magnetometer、airspeed。本地 docs/config_robot.md、docs/sensors/camera_capture_settings.md 与官方文档已核对。相机的深度、分割、法线是输出类型；雷达当前为真值/射线简化模型，不能视为真实电磁仿真。现有 WISEYE 红外仍为自定义合成热成像，现有云台点云为 UE 查询实现；添加其他 AirSim 传感器还需挂载姿态同步和独立适配，不能只改 UI。
