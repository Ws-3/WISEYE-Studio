## 初始放置与命名预设

1. 连接后进入“场景编排”，选择与 UE 当前运行一致的场景。可先在工作台选择“自由观察”，在 UE 按住右键 + WASD 调整到合适视角。
2. 选择无人机或云台，点击“到 UE 点击放置”，切到 UE 左键选中向上的表面；青色标记只属于观察窗口 HUD，不写入光电图像。右键取消，45 秒超时自动退出。该过程会进入观察输入模式，结束后按需要重新选择驾驶模式。
3. 也可输入 X/Y，点击“当前 X/Y 贴合表面”。从输入 Z 上方 1000 m 向下查询 2000 m，选择首个朝上的静态碰撞表面；屋顶/平台也可选，未启用碰撞的场景资源无法命中。当前设备本身与 AirSim 代理被忽略。
4. 无人机默认距表面 0.25 m，作为物理机体的初始余量；加载后会自然落到接触高度。云台自动按外壳最低点校正安装点高度，可再加“距表面高度”。取点/贴合只写草稿，不立即移动正在仿真的设备。
5. 填写名称并“另存为新预设”，或者选择已有命名预设再“更新所选预设”。读取命名预设只填入草稿；要成为场景起始配置，还需点击“保存初始布置”→“加载所选场景及已保存布置”。

当前生效的初始布置仍是 `Config/WISEYE/Layouts/<scene>.json`；命名库位于 `Config/WISEYE/Layouts/Presets/<scene>/<preset_id>.json`，可随 Git 同步。中文名称存在元数据中，文件 ID 自动生成。相同场景不允许重复名称；更新只针对已选择的现有预设，不覆盖基础地图。损坏的单个预设会提示，不隐藏其他预设。

编辑坐标或预设名称时不会触发驾驶；草稿坐标不会因实时状态轮询被重写。断连会丢弃等待中的结果，不把旧坐标写回草稿。重新连接后若 UE 仍在取点，可点击“取消取点”；也可在 UE 右键取消。当前没有设备模型拖拽预览、三轴操纵杆、地表法线对齐或初始姿态编辑。

## 新电脑首次配置

### 从 GitHub ZIP 下载的情况

ZIP 不包含 `.venv`，所以首次点击 Start-Desktop 可能提示 `Desktop environment missing`。在解压后的项目根目录创建本机环境即可，不需要重新下载工程，也不需要激活 conda WISEYE：

```powershell
cd D:\Projects\WISEYE-Studio
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\Start-Desktop.ps1
```

上面的目录请按本机实际位置修改。当前启动脚本固定使用 `.venv\Scripts\pythonw.exe`；只在 conda 环境安装依赖不能满足该检查。更新 ZIP 时保留本机 `.venv`，如 requirements.txt 有变化，再运行安装命令。ZIP 没有 `.git`，不能直接在解压目录执行 git pull；需另行 git clone 才能使用 Git 同步。

以下 E 盘路径和“已配置”状态来自另一台电脑的历史记录，不代表刚解压的电脑已经安装依赖。

安装 Git、UE 5.8（验证 5.8.3）、Visual Studio 2022 C++ 游戏开发工作负载（MSVC v143、Windows SDK），以及 Python 3.12 或更新版本。当前本机实测 Python 3.14.6 / PySide6 6.11.0。

在 PowerShell 中执行（引擎路径按本机修改）：

```powershell
cd E:\Projects
git clone https://github.com/Ws-3/WISEYE-Studio.git
cd WISEYE-Studio
Set-Content -Path scripts\engine-root.local.txt -Value 'E:\Programs\UE_5.8'
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\Start-WISEYE.ps1
```

UE 加载后点击播放，再运行：

```powershell
.\scripts\Start-Desktop.ps1
```

不需激活虚拟环境；启动脚本固定使用本仓库 `.venv`。不要复用或升级已有训练环境。模型、材质、关卡都在 Git 中，无需重新导入。每台电脑的引擎路径与虚拟环境不上传。

## 排查

- 连接失败：确认 UE 已点击播放；仅打开编辑器不会启动 TCP 服务。地址使用 127.0.0.1、端口 50051，并检查 UE HUD 的 Bridge 状态。
- 提示缺少桌面环境：按上面创建 `.venv` 并安装 requirements。
- 使用 Anaconda 创建 venv 时出现 QtCore/QtWidgets `DLL load failed`：2026-10-15 的桌面入口已处理系统 ICU 与 conda 同名 DLL 的冲突；用 Start-Desktop 或 `python -m apps.desktop_app.main` 启动，不要删除 conda 的 DLL。
- 首次 UE 构建失败：检查 VS 的 C++ 工作负载和 SDK；关闭已保存的旧 UE 编辑器再构建。不要只复制另一台电脑的 Binaries。
- 引擎找不到：修正 `scripts/engine-root.local.txt` 为包含 Engine 子目录的安装根目录。
- CH1/CH2 不更新：确认由 `scripts/Start-ProjectAirSim.ps1` 启动了 RTSP 服务，`ffmpeg -version` 可运行，并检查 `logs/rtsp-gateway-error.log`；“保存当前传感器”仍是单帧 PNG/PLY 导出。
- 桌面报错：在仓库运行 `.\.venv\Scripts\python.exe -m apps.desktop_app.main` 查看终端输出，日志在 `logs/desktop_app.log`。

当前桥仅监听回环地址；另一台电脑需自行运行 UE 和桌面窗口。跨电脑同步的是 Git 工程，当前不是两台电脑远程连接仿真。

## 2026-10-19：键盘与按钮操作

系统窗口先确认 UE 和 AirSim 飞控均已连接，选择“手动飞行”，按 W/S 前后、A/D 左右、R/F 升降、Q/E 转向；按钮需按住。下拉框/按钮获得焦点时仍可使用飞行键；编辑地址或数字时优先输入文字，不发送飞行命令。松键或窗口失焦会发送零输入并悬停。选择手动模式也会退出悬停暂停状态。

UE 内先进入 Play、点击游戏画面，按 M 进入手动，再用 WASD、↑↓、Q/E；空格暂停/恢复，R 复位，T 跟踪/保持，Tab 视角切换。AirSim 暂停是物理悬停，物理时钟继续；外观仍跟随物理位置，避免起飞/降落时画面冻结。

停止再播放 UE 后，飞控服务会检测新会话并重新加载当前场景，桌面自动恢复飞控连接。若仍显示未连接，检查是否从 scripts/Start-ProjectAirSim.ps1 启动，勿同时运行两个 runner。

设备外形：Mavic 3 机身不含桨叶为 34.75×28.3×10.77 cm；初代 Avata 含护圈为 18×18×8 cm；云台高 80 cm。真实尺寸的 Avata 会明显小于 Mavic，可使用视角切换/变焦查看。

Avata 自身四组桨叶已拆为独立动态旋翼；选择 Avata 后使用系统“旋翼”按钮控制开始/停止。在 UE 游戏画面内按 F 同样生效；系统窗口内的 F 是手动下降键。旋翼当前使用统一视觉 RPM，并非 AirSim 各电机实时转速。

默认视觉转速已由 600 提高到 6000 RPM。两种型号在高速时显示半透明扫掠圆盘，避免帧率采样造成桨叶像慢转或倒转；关闭旋翼后恢复清晰桨叶。圆盘是高速视觉近似，不是电机遥测或光学曝光仿真。

点云页默认三维投影，可拖动旋转、滚轮缩放、双击复位，也可切换正视 Y/Z 或俯视 Y/X。三种视图均采用米制等比例，颜色为近青远红，并显示坐标轴、距离和比例尺。点是当前一帧真实回波，不累计为完整地图；地面回波出现条带或平面、小目标只有几个点，可能符合当前 576 条射线和 30°×8°视场。零命中会显示“本帧无回波”，可用云台保持/角度调整朝向有实体的区域。
