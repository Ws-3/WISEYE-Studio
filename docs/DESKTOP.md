# WISEYE 桌面端 · v1.1.0

源码双击根目录 Start-WISEYE-Studio.vbs，或运行 scripts/Start-Desktop.ps1；完整包运行 WISEYE.exe。**打开界面不自动启动 UE。** 在场景编排选择场景，从右上角启动/关闭仿真；连接/断开按钮控制数据连接，不代表 UE 正在推进。

工作台以场景观察和传感器画面为主，驾驶对象、云台控制对象、画面来源分别选择。可拖动/调整画面、滚轮缩放、弹窗和全屏。机载可见光/红外双光并排；点击画面不自动打开参数窗口。参数在对应传感器/设备中编辑并应用，未启用传感器停止其相应采集，不停止飞控连接。

右侧操作栏负责驾驶、键盘归属、起降和云台遥杆。实时遥测包含目标距离、云台角度/FOV与设备位置。环境、天气、画质与性能从场景菜单进入；诊断显示连接/推进/资源准备等状态，低性能评估不等于基准测试结果。UE 窗口可手动弹出/收回，隐藏仍会渲染和使用 GPU。

新增、删除或修改设备可应用到当前运行场景；保存初始配置独立进行，受影响的飞机移动/跨类/删除前需停止。换地图会重建会话。具体操作见[用户指南](USER_GUIDE.md)、[实时设备](LIVE_DEVICES_20261105.md)与[云台坐标接口](GIMBAL_COORDINATES.md)。

本机默认 127.0.0.1:50051 控制桥；训练数据服务默认 50100，RTSP 默认 8554。内部快速预览直接取最新帧，不走 RTSP 编解码往返。跨机服务用于可信局域网，尚无完整身份认证/TLS。见[协议](PROTOCOL.md)、[RTSP](RTSP.md)及[训练端](../training_client/README.md)。

唯一原生工程在 ue5/WISEYE；不依赖外部旧 IR-Work/Evaluation 开发副本。安装、版本更新、UserData 和兼容性见[安装指南](INSTALLATION.md)与[发布指南](RELEASE_BUILD.md)。
