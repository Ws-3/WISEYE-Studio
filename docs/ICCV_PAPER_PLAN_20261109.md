# WISEYE：面向 ICCV 的论文结构与研究计划

日期：2026-11-09。本文是选题与实验设计草案，不是已完成论文；所有方法创新与性能收益均待文献核查、实现和实验验证。当前唯一开发源码为 `E:/Projects/WISEYE`。

## 1. ICCV 的定位与投稿目标

ICCV（International Conference on Computer Vision）是计算机视觉顶级学术会议，不是期刊。CVF 将 CVPR、ICCV、ECCV 列为本领域三大主要会议；CCF 2026 目录将 ICCV 列入人工智能领域 A 类会议。主会正式长文、Workshop、Demo 等应明确区分，不能统一标成“ICCV 主会论文”。具体毕业、职称与奖励认定以所在单位规则为准。

截至本次查询，ICCV 2027 官方页面公布举办地点为香港；Dates 页面只有会议日程，尚未列出论文投稿截止日期。不要把上一届截止日或第三方预测作为已确认日程。页数、匿名、数据/代码、补充材料与 AI 使用披露等要求，待本届正式征稿与作者指南公布后逐项确认。

## 2. 推荐选题及范围

暂定中文题目：**面向真实小目标无人机检测的传感器感知仿真校准方法与评测**。

暂定英文题目：**WISEYE: Sensor-Aware Simulation Calibration for Sim-to-Real UAV Detection**。

核心研究问题：在真实标注数据有限的条件下，能否用独立的真实校准样本约束仿真成像与采样分布，让等量合成数据在未见真实场景中的无人机检测上，比人工外观调参和普通域随机化产生更稳定的收益？

主任务建议收敛为“地面光电云台观测空中无人机的小目标检测”，先完成热红外的完整证据链，再将可见光作为第二模态验证。只有获得可靠配准、同步且许可清楚的真实双光数据，才将 RGB-T 融合纳入主方法。

航拍地面车辆/行人与地面观测空中无人机是不同任务。HIT-UAV 等航拍地面目标数据可用于辅助成像分析或单独扩展实验，不直接替代本论文的真实反无人机测试集。事件相机、LiDAR、JSBSim、界面和打包作为平台背景或补充材料，不同时扩展成多个研究主线。

## 4. 候选贡献：待验证，不作为现成结论

### C1. 面向微小无人机的可控成像代理

统一描述目标投影尺度、观测角度、双镜头外参、PSF/离焦、目标与局部背景对比，以及热外观分布。关键是让参数与可观测图像属性建立可复现关系，而非新增一组主观“真实模式”。

小目标退化应在正确的分辨率和成像链顺序下作用；分别检查先高分辨率渲染后缩放、直接低分辨率成像、模糊/噪声/压缩顺序，防止模型利用仿真特有边缘。红外显示灰度受 AGC 和极性影响，不能直接解释为温度。

### C2. 少量真实样本驱动的参数分布校准

拟研究一种按目标像素尺度和背景条件分组的校准方法，学习仿真参数的分布，而不是把所有场景调成一套固定数值。先提出机制和可检验假设，再决定是否增加复杂学习模块。

可行的起点是：在真实校准集上提取目标/背景局部对比、边缘扩散、纹理频谱和噪声等统计，对应生成同尺度/背景条件的仿真样本，通过黑盒搜索拟合参数分布。UE 不必可微；不把无法从非配对图像唯一确定的参数冒充为真实硬件反演结果。边缘/噪声统计会同时受纹理、压缩与运动影响，应报告不确定性和参数敏感性。

候选目标形式：`统计距离 + 参数先验约束`。可另设使用真实开发集检测损失的任务引导扩展，但必须披露其使用的真实标签和调参预算，给对照方法相同预算；最终测试集完全不参与拟合、选参和早停。无标签校准与有标签开发不能混称为无监督方法。

需要回答：对极小目标，哪些成像因素最影响真实检测？整体直方图更接近是否足够？按尺度校准是否优于统一风格调整？校准是否会牺牲未见背景的覆盖范围？

### C3. 可复现的真实迁移基准与机制分析

发布可分享的配置、生成种子、实验划分清单、训练/评估脚本及权重，报告跨场景、跨目标尺度和跨检测器的结果。平台、数据集、评测分析均可能成为论文贡献，但需要独立的研究价值，不能仅以功能数量作为依据。

上述三个方向尚未完成系统性新颖性检索。“热红外合成数据用于检测”已有相关工作；不能把这个概念本身写成首次提出。重点核查合成热像、任务驱动仿真校准、域随机化、无人机小目标与传感器退化建模的交叉工作。

## 5. 主文结构

### Abstract

按“真实问题—现有不足—所提方法—实验协议—实测发现”写。当前只写问题和方案，所有结果用明确的待填占位符，不预设成功幅度。

### 1. Introduction

1. 地面无人机检测的真实数据长尾：小尺寸、远距离、复杂背景和昼夜变化。
2. 合成数据容易获得，但人工看起来像，并不保证真实检测有效。
3. 提出可检验的研究假设：目标尺度与局部成像统计的条件校准，比单纯追求画面观感更有助于迁移。
4. 总结经过实验支持的贡献。暂不写“首个”“物理精确”或“全面超越”。

### 2. Related Work

- 无人机可见光/热红外检测与小目标；区分检测数据和单目标跟踪数据。
- 仿真平台、合成数据生成和热红外合成增强。
- 域随机化、仿真参数校准、合成到真实迁移。
- 光学退化与传感器成像建模；区分外观逼近和辐射定标。

用表格比较“任务、视角、模态、参数是否可控、是否真实测试、是否自动校准”。未复现的方法不随意写成性能弱于本方法。

### 3. Task Definition and Data Protocol

- 输入、类别、检测输出，以及真实标注预算。
- 仿真参数空间与真实校准/开发/最终测试的使用权限。
- 训练、调参与测试的场景/序列隔离。
- 主评测是检测；不把单目标跟踪标注的未知干扰物当成已完整标注的检测负样本。

### 4. Method

4.1 可控场景与观测几何：目标位置/姿态、光心、外参、投影尺度、遮挡。

4.2 传感器成像代理：可见光 PSF/离焦/噪声与热红外材料/局部热区/显示链；清楚标出经验参数和物理近似。

4.3 条件化校准：特征、损失、优化方式、校准预算、约束与停止标准。

4.4 数据采样与标注：场景覆盖、难例比例、真实/合成混合方式，同帧标注、可见性与截断规则。

给出伪代码和参数表；重点解释为何这些设计能影响真实检测，而不逐页介绍软件按钮。

### 5. Experiments

5.1 数据、划分、检测器、训练预算和指标。

5.2 等数据量/等训练预算主对比。

5.3 参数与模块消融、真实校准样本量曲线。

5.4 未见场景、无人机外形、像素尺度、背景与昼夜泛化。

5.5 效率、失败案例和收益边界。

### 6. Limitations and Responsible Release

经验热像代理与真实辐射物理的差距、真实数据覆盖不足、极小目标标注不确定性、合成偏差与校准过拟合。说明数据来源、素材许可及可再发布范围；City Sample 等第三方资源不默认随论文重新分发。评估视频隐私，披露仿真数据和真实数据，不将合成结果冒充实测。

### 7. Conclusion

只总结实际支持的结论：什么条件下有效、增益是否稳定、哪些情况仍失败。

## 6. 数据划分与可信度底线

1. 本机 `F:/DATASET_UAV_BICE/YOLO_UAV_BICE` 的 Halmstad、CESE 先审核来源、许可、类别映射、序列与标注完整性；不修改原始数据。目录名、转换后文件名不是来源和配准的充分证明。
2. 按原始视频/采集地点/采集日期划分，不随机打散相邻帧。重复图、裁剪图、同一视频的不同数据集别名也要去重。
3. 分清真实训练集、校准集、开发集与最终测试集。少数据时可设计合规的序列级嵌套划分，但不能反复查看最终测试后继续调参。
4. 现有 66 图探索样本及已经展示、用于人工调参的实拍只能作为开发证据；为最终结论另保留未参与开发的序列。单看测试样例不等于自动污染所有数据，但据此选参的部分必须披露。
5. 空 YOLO 标签不自动视为可信负样本；跟踪数据通常未标全所有目标，改用于检测评测须补审。Anti-UAV 系列需要逐版本核查任务、许可和完整标注，不能直接混用名字。
6. RGB/IR 联合实验须校验时间和几何对应；无法验证时做单模态实验，不声称双光融合结果。
7. 距离未知的真实图用目标像素尺度分组，不从框大小伪造真实米数。

## 7. 最小实验矩阵

所有混合训练组固定相同真实标注预算；合成对比固定相同图像数量、训练步数、输入分辨率、检测器、预训练权重和常规增强。额外报告生成成本及超参数搜索预算。真实数据重复采样的等步数基线用于排除“只是训练更多”的解释。

| 编号 | 训练数据/生成方式 | 作用 |
| --- | --- | --- |
| R | 仅真实训练数据 | 判断现有真实数据基线 |
| S0 | 仅未经本方法校准的仿真数据 | 测量原始合成到真实差距 |
| S1 | 仅校准后的仿真数据 | 观察不混入真实训练标签时的迁移；仍披露校准是否用过标签 |
| R+S0 | 真实 + 基础仿真 | 分离合成数据本身的效果 |
| R+DR | 真实 + 常规域随机化仿真 | 与不利用真实校准信息的随机化比较 |
| R+Manual | 真实 + 人工外观调参仿真 | 对比当前工程路线；人工与自动调参预算单独记录 |
| R+Ours | 真实 + 拟研究的条件校准仿真 | 验证核心假设 |

R+DR 与 R+Ours 的资产、场景覆盖和可调参数范围应尽量一致；增加给基线相同真实开发信息/搜索预算的对照，避免把获取更多数据算成方法收益。代表性的既有合成增强/校准方法待文献复核后加入，不以本表替代相关工作对比。

至少使用两个结构不同的检测器，优先 3 个随机种子；若计算受限，应缩小实验规模而不是隐瞒随机性。置信区间按序列/独立场景重采样，避免把相邻帧视为独立样本。

主指标：AP50、AP50:95、预先规定像素尺寸分组的 AP/召回，以及固定虚警水平下的召回率。极小框对 IoU 极敏感，可补充中心误差/定位容忍指标，但保留标准 AP，解释标注误差而不为某方法事后换指标。

像素尺度可预注册短边 `<4`、`4–8`、`8–16`、`>=16` 像素等自定义分箱，明确不是现成 COCO 官方分组；评估 `<4` 像素样本是否具备可靠标注。若数据量不足，应在查看最终测试结果前合并分箱。

图像诊断可报告局部对比、边缘和噪声分布，但非配对实拍/仿真不使用逐像素 SSIM 作“真实性证明”，FID 或直方图接近也不替代真实任务结果。

必要消融：按尺度校准 vs 全局校准；光学退化；局部目标/背景热结构；参数分布覆盖；采样策略；真实校准预算。双镜头几何仅在真实双光任务中作为核心消融，避免给单模态检测增加无关论证。

## 9. 执行顺序与停止条件

### 阶段 A：选题与数据审计

- 系统检索相关文献，形成任务/方法/实验差异表，确认候选方法不是重复已有工作。
- 核查地面观测无人机实拍数据的序列与许可，建立冻结划分清单和哈希。
- 选定主模态、任务与标注预算，审核极小目标和负样本。

### 阶段 B：最小真实任务验证

- 先跑 R、R+S0、R+DR、R+Manual；再实现最小可行校准原型，与 R+Ours 比较。
- 小规模阶段先核验加载/标签/训练是否正确；正式结论重复种子并扩展检测器。
- 若等预算下没有可重复的真实测试收益，先查标签、分布、采样与成像链，不批量生成海量数据或预写成功结论。允许结果否定原假设。

### 阶段 C：补全方法与正式评测

- 根据开发集证据完善校准机制，锁定超参数，冻结最终实验协议。
- 补跨数据集、尺度、背景、夜间与失败案例；有真实配对数据后再决定双光扩展。
- 检查统计稳定性、计算预算和数据泄漏，保存每次训练配置、版本与产物。

### 阶段 D：写作与开放材料

- 先写协议和方法，再根据完整结果撰写摘要与结论。
- 准备匿名代码/材料、可再发布的数据索引与生成配置；清除公开包中的账号/路径信息。
- 依据 ICCV 2027 正式指南核对匿名、篇幅、补充材料、数据声明及 AI 使用要求；不要把工程验收等同于投稿就绪。

本轮仅完成研究计划，没有启动训练、下载完整新数据集、修改渲染或验证任何 AP 收益。下一步的优先产物是“相关工作差异表 + 数据划分清单 + 最小训练基线”。
