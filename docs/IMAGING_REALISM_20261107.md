# 双光成像改进：2026-11-07

源码：`E:\Projects\WISEYE`；运行预览工程：`E:\Projects\WISEYE-IR-Work`。修改作用于UE源相机输出，桌面、导出及训练预览共用，不是界面截图滤镜。

## 红外

- 道路原先基本返回单一类别热值，缺少铺装细节。现在结合材质BaseColor/粗糙度及世界坐标固定的11.7m/2.9m尺度缓变热场。材质线索不是可见光阴影复制；热场不使用时间、屏幕UV或逐帧随机噪声，因此移动镜头不会让纹理粘在屏幕上。
- 道路昼夜基础信号适度下调，保留道路与墙面、植被、玻璃等类别的差别。未标定水平表面只有弱表面响应，不将所有屋顶标成道路，不保存或重新标记城市外部Actor。
- 航拍独立使用较缓的背景显示曲线，并平滑按昼夜改变中点，解决沿用天空占比高的云台曲线导致夜间地面过黑。原有云台背景显示参数仍为0.68/8，航拍白天0.60、夜间0.36、斜率4。
- 原始热代理信号与显示变换分开；目标和天空不经过新的航拍背景曲线，保留无人机电机/电池热差、独立模糊和噪声、极性切换及AGC稳定机制。
- `devices[].aerial.infrared`在捕获资源分配期间新增可选诊断字段：`agc_low`, `agc_high`, `readout_ms`, `readout_sequence`, `class_pixels`。资源释放后字段可能缺省，不能将缺省值当零温度或零目标。

这仍是归一化合成热信号及外观代理，不能读作摄氏度、真实材料发射率或经过热传导求解的温度场。没有重建全部城市材质，也没有加入第三方付费插件。

## 可见光

- 以保留黑白端点的平滑对比曲线替换旧线性灰底公式。中性参数仍为对比1/饱和度1，暗部不会因对比参数默认0.96而统一增加约5灰阶。
- 保留可编辑光学模糊（默认0.55px）、基础噪声0.006、对比0.96、饱和度0.88。现有用户参数不被重置。
- 使用两个独立随机分量和很弱的固定噪声，夜间增益平滑升高，保留细小成像噪声。没有新增CPU全图处理、历史帧平均或视频编码往返。
- 航拍复用可见光相机的响应与天气，红外继续使用独立镜头、HDR热读回和640×512输出；可见光仍1920×1080。两者6cm基线及0.2°航拍视轴差保持。

没有新增“超清/实拍”等风格模式，也没有写死强雾、运动拖影、彩边或污渍边框来伪装真实。曝光/天气原有控制保留；本轮不是实机镜头、快门、增益和响应曲线的量测标定。

## 重建与使用

1. 正常使用源码预览时，关闭旧仿真后重新启动即可载入更新材质和模块。
2. 在新电脑恢复预览工程时，先同步唯一源码`ue5/WISEYE/Source`并构建`testEditor Win64 Development`，不要直接修改外部构建副本当成主源码。
3. 需要重新生成资产时，对实际预览工程运行`UnrealEditor-Cmd.exe <project> -run=pythonscript -script=<source>/ue5/scripts/configure_imaging_realism.py`；保存的`M_IR_Facade.uasset`和`M_VisibleCamera.uasset`同步回源码对应Content。不要只复制HLSL而不重建材质。
4. Shader输入WorldPosition仅加在Facade材质。原参考/Classified资产不需要新增输入。新原生模块需与新材质一起部署。
5. 独立运行包需重新编译、Cook及打包；本轮不自动覆盖旧发行包或推送GitHub。
