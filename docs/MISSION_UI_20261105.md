# 面向观测与航拍任务的工作台改版

工作台顶部新增“云台观测 / 无人机航拍”两个任务入口。航拍不再作为场景菜单里的弹窗功能：相机编辑器常驻右侧，相机来源、俯仰、水平转向、FOV、前/斜/下视和可长按方向按钮直接操作。电源、稳定模式和采样率折叠到“相机与采样设置”，应用与保存默认沿用原有请求确认逻辑。

进入航拍默认只显示一幅机载主画面，收起设备树；“场景参考”可加入UE观察画面。保存原始帧位于画面上方，未收到当前有效帧时禁用。切回云台观测恢复进入前的画面、布局和设备栏；临时航拍布局不覆盖持久化的观测布局。原来的放大、弹窗和图像缩放继续可用。

右侧起飞、悬停、降落保持可见，驾驶对象与相机来源分别标明。预览其他无人机的相机不会改变驾驶对象；需要切换时点击带目标ID的“切换驾驶到…”按钮，再明确接管键盘。航拍任务中仅保留“驾驶 / 相机”上下文，隐藏无关云台参数入口。选择相机、切换布局都不自动发起起飞、降落或手动接管。

场景级的天气、人车密度、画质和运行诊断统一在“场景设置”菜单。左侧只保留简短运行状态，GPU型号、显存详细信息归入运行诊断。移除重复航拍菜单、航拍主画面中的同名按钮和不适用的布局切换；修复无人机名称与ID相同时重复显示。原有设备管理、数据接口、资源设置及训练端入口保留，训练端本轮未改。

## 验证与截图

新增任务界面测试覆盖嵌入式编辑、换相机不接管、场景参考、布局切回及持久化保护、保存帧可用性。相关界面与既有预览测试结果在 `docs/evidence/mission-ui-20261105/`。一次组合进程中断记录不作为通过依据，以最终日志为准。

实际隔离UE小城运行验证：右侧机载编辑器可连续转向、改变俯仰，1920×1080源帧随之变化，驾驶对象保持，所属测试进程退出；没有发起起飞。原始实机截图为 `live-workbench.png`。最终细节调整后的布局截图 `aerial-layout.png`、`aerial-1100.png`、`observation-layout.png` 使用同次实测帧回放，顶部明确标注布局检查，非另一轮实机性能验收。1600×1000和1100×760布局均检查，较小窗口保留右侧滚动。

实现：`mission_workspace.py`组合现有SensorWorkspace、ObservationDialog及飞控命令所有者；保持现有主页面和控制协议索引。只改变桌面交互与布局，重启桌面即可使用，无需重编译UE。未重新打包或推送。
