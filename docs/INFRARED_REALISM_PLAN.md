# 红外逼真度与 Anti-UAV 对齐方案（2026-10-26）

实施更新：相机外观试验第一版已经完成并在真实城市验收，见 [试验说明与运行入口](INFRARED_EXPERIMENT.md)。下文是完整目标路线，尚未实施的物理模型与热材质工作不可当作已交付。

## 现状与目标

`WiseEyeSensors.cpp` 按机身/电机/旋翼写入 CustomDepth Stencil 热度，`/Game/WISEYE/Sensors/M_IR_Minimal` 根据背景热度、天空热度、噪声与黑白热生成图像。它能区分目标和背景，但没有完整场景温度、材质光谱发射率、传输和相机模型。城市的可见光纹理不能直接等同于长波红外纹理，因此单纯灰度化/加噪点会保留错误的背景反差。

目标先定为“外观与统计接近真实热像”，保留640×512原始输出、真值和时间戳；需要真实温度测量或辐射计量时再引入有校准依据的模型。不能把视觉接近声称为辐射精度或算法跨域能力已验证。

Anti-UAV、Anti-UAV410、CST Anti-UAV是不同数据集，不应混写相机规格。CST论文明确说明25fps、640×512，并包含城市、建筑、天空等复杂背景；可作为当前城市版参考。正式调参前，从获准使用的真实数据选取天空/建筑/树木背景、近中远目标及昼夜片段。锁定参考版本和数据许可，不复制样本进入公开仓库。

## 推荐实施顺序

1. **场景热特性**：建立建筑混凝土/玻璃/金属、道路、植被、水面、天空的热材质类别，区分环境温度、日照、热惯性、发射率与反射。机身/电机/电池分开，电机温度随真实运行状态平滑升降；不将全部机身画成均匀白块。玻璃与水面须考虑热反射，而非照搬可见光明暗。先覆盖Small City主要材料，再核查Nanite/实例/流式加载一致性。
2. **光学与尺度**：明确波段（首版可选通用8–14μm LWIR预设，并标注是工程假设）、焦距/FOV、像元与距离；通过真实尺寸和距离得到目标像素数，不缩放无人机模型造小目标。加入受控PSF/MTF模糊和亚像素能量响应，避免锐利剪影和远距离目标突然消失。
3. **相机管线**：热信号→大气透过/路径项→光学模糊→噪声/FPN/坏点（可独立开关）→位深与增益→AGC/黑白热→640×512输出。AGC加入时间平滑，噪声按帧号固定种子复现；不要每帧随机改变背景材质。首版大气模型是近似参数化，不能宣称MODTRAN精度。
4. **数据域校准**：按背景、距离、目标大小分组，比较目标背景对比、背景灰度直方图、噪声频谱、边缘宽度和时间稳定性。保留未用于调参的真实片段验证；再用真实测试集检查检测/跟踪泛化，不能只看截图。保留无噪声真值输出和相机输出两条逻辑数据流。
5. **性能**：优先GPU材质/计算着色器，热场慢速更新、相机按采样率输出，共用一次热图避免每个输出重复渲染；桌面和RTSP引用同帧。维持现有最新帧策略与原始时间戳。对1机2云台先测帧时间和P95延迟，再扩多设备，不默认提高渲染分辨率。

建议参数归属：每传感器配置 `thermal_profile`、环境/材质模型引用、PSF宽度、噪声强度、AGC范围/响应时间、坏点率、随机种子；发布主机与RTSP路径仍属于接口配置。字段、单位、有效范围、默认值和配置版本须落盘，不能仅加界面滑块。本轮尚未修改UE红外渲染。

## 插件路线

| 候选 | 官方能力 | 对本项目的判断 |
|---|---|---|
| 自建轻量热材质与相机后处理 | 完全可控，接入现有多设备与打包结构 | 首选做外观/统计逼近；能控制额外GPU开销，不承诺计量精度 |
| ThermoForge | 温度场、气候、热源、采样和热视觉后处理 | 可评估热场模块，官方明确不是科学热力学求解器；不能安装后就声称是真实红外相机 |
| Infinite Studio | 厂商称提供光谱材质、MODTRAN大气、镜头/探测器/读出噪声与辐射建模 | 适合需要物理辐射建模的商用方案评估；不是已确认可直接嵌入本项目的普通免费插件 |

所有第三方接入前先在隔离副本验证UE5.8.4、Windows Shipping、Intel Arc B580/DX12、Nanite/World Partition、原始输出、多云台与再分发授权。商业价格、兼容版本、打包授权和性能均需向供应商核实，本轮未采购、安装或确认兼容。不要选必须CUDA的实现给当前Intel显卡直接使用。

结论：可以逐步做出接近Anti-UAV观感的结果，推荐先自建热材质+传感器模型并用真实片段调参；若需求升级到可标定的辐射仿真，再评估商业引擎。
