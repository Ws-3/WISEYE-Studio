# WISEYE Training · v1.1.0

训练数据工作台负责云台/航拍来源发现、预览、采集、人工标注、样本审核与数据集导出。它不代表已经训练出检测模型，也没有自动模型上线流程。

## 运行和连接

完整包运行 `Training/WISEYE-Training.exe`；仿真端可直接打开训练端。源码使用本目录 `Start-Training.vbs`，或在仓库根目录安装依赖并启动：

```powershell
python -m pip install -r training_client/requirements.txt
python -m training_client.preview --host 127.0.0.1 --device ptz-01
```

本机地址 127.0.0.1，跨机填仿真电脑 IPv4；数据服务默认 50100，随仿真启动和退出。跨机需允许对应 TCP 端口入站，仅用于可信局域网，尚无认证与 TLS。RTSP 默认 8554，为独立视频接口；UE 控制端 50051 保持本机，不应直接暴露给算法电脑。

独立数据客户端不要求算法电脑安装 UE 或 AirSim。单独复制源码客户端时保留本目录所有 Python、主题和依赖文件，配置/语言资源缺失时与完整仓库的行为可能不同；不要只复制一个入口脚本。仿真服务与客户端应使用同版协议。

## 快速预览和标注采集

快速预览取最新画面以减少积压，不包含逐帧同步 GT；标注采集单独请求并校验样本，速率受渲染、GPU 读回、GT、网络和磁盘限制。显示和保存独立限速，只保存新样本，不补重复帧。配置上限不是实测帧率；历史 4–5 组/s 是旧路径本机记录，不是本版固定吞吐保证。

云台来源可选择可见光、红外或双路；双路按 pair_id 与 simulation_time_s 配对，两路独立 frame_number 不必相等。GT 叠框只改变显示，不改变原图、标注或保存策略。融合是观察工具，不是已完成深度配准的训练真值。

航拍来源可选择设备及可见光/红外。当前采集为待标注原图，不产生自动 GT，不保证机载双光同 Tick 或逐像素配准。切换来源后确认设备 ID、模态和数据目录，不能用云台 GT 标记航拍图。

## 记录和保存

云台配对数据保留原生可见光 1920×1080 与红外 640×512，分别保存原图、YOLO 标签和 JSON 元数据。默认结构：

```text
visible/
  images/
  labels/
  annotations/
IR/
  images/
  labels/
  annotations/
```

文件名包含传感器、机型/环境上下文、场景/设备、运行会话和组 ID；双路除模态前缀外共享组标识。JSON 保存拍摄上下文、相机参数与配对信息，不用单张检测框推断同步或配准精度。普通保存异常会回滚新增文件，不覆盖历史样本；断电或强杀仍可能留下未完成组，后续校验应拒绝坏组。

航拍使用 schema 4，初始状态 pending_manual。必须人工标框，或明确确认该图为负样本；未经审核的空框不等于负样本。当前编辑器类别为无人机、行人、车辆；已有云台自动 GT 在此编辑器中只读，不能混用 schema 或覆盖成手工样本。

## 数据集审核和导出

先扫描目录、验证图像/元数据/标注，再进行人工拖框和审核。导出按运行 run 分组隔离，避免同一序列跨训练/验证划分；导出前必须检查类别、样本状态、配对完整性和负样本策略。后台导出可取消，既有数据不因取消被覆盖。

真实数据与仿真数据应分别记录来源和许可，禁止把模拟 GT 当实拍标注或把待标注航拍当负样本。完整操作及测试范围见[航拍采集和数据集](../docs/AERIAL_IR_TRAINING_20261107.md)。

## 几何、速率和能力边界

云台 VIS/IR 是独立光心，可设置基线、安装角差和各自 FOV；同刻采集不等于像素已对齐。旋转投影补偿仍保留基线产生的深度视差。取帧耗时是请求至返回的端到端时间，不是单向网络延迟或硬件曝光时间。

红外未做辐射温度定标，画面退化为工程近似；航拍地面目标尚无自动 GT。实际训练脚本及算法依赖需要另行准备，数据集导出成功不代表论文检测实验或算法性能已完成。

本版本随源码插件/完整软件双交付发布。完整包已包含冻结训练端；SDK 本身不含训练端 Python 环境。安装、分发与验证见[v1.1.0 发行说明](../docs/releases/v1.1.0.md)、[插件指南](../docs/PLUGIN_DISTRIBUTION.md)及[协议](../docs/PROTOCOL.md)。
